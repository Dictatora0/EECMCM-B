# Plot Outputs

本目录保存统一绘图脚本生成的图表产物与图表清单。

## 目录结构

- `png/`
  - 论文写作、快速预览最常用。
- `pdf/`
  - 适合论文插图与打印。
- `svg/`
  - 适合后期排版微调。

## 清单文件

- `plot_manifest.csv`
  - 每张图的输入文件、导出路径、推荐位置、生成状态。
- `plot_notes.md`
  - 图表用途说明。
  - 已区分“正文推荐图”“附录推荐图”“因缺失跳过的图”“表格更直观而跳过的图”。

## 论文引用建议

- 先看 `plot_notes.md` 的“正文推荐图”；这里再给出更短的论文入口版。
- 正文引用时优先使用：
  - `pdf/` 或 `svg/`
- 快速核图时优先使用：
  - `png/`
